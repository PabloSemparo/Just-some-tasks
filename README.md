# Just Some Tasks

A personal collection of small programming exercises, practice tasks, and code snippets.

The repository is primarily focused on **JavaScript**, with a few examples in **Java**. The exercises are kept as separate files so that each task can be explored independently.

## What you'll find here

The repository covers a range of beginner-friendly programming concepts, including:

- **Variables and data types** — declaring values, working with strings, numbers, and booleans.
- **Functions and expressions** — parameters, return values, arrow functions, and conditional expressions.
- **Control flow** — `if/else`, `switch`, loops, and decision-making.
- **Arrays and objects** — creating, reading, updating, and iterating over data.
- **String manipulation** — formatting, masking, truncating, and analyzing text.
- **Math and calculations** — arithmetic operations, random values, rounding, and simple statistics.
- **Small practical programs** — examples such as a quiz game, lunch picker, recipe tracker, wildlife tracker, and cargo manifest validator.
- **Algorithms** — sorting and basic array-processing tasks, including Java examples.

## Languages

| Language | Purpose |
| --- | --- |
| JavaScript | Most of the exercises and small programs |
| Java | A small number of algorithm and calculation examples |

## Repository structure

Each exercise is stored in its own source file in the repository root. File names describe the task or topic.

Examples include:

| File | Topic |
| --- | --- |
| `Card_Counting_Assistant.js` | Card-counting logic and conditional decisions |
| `Cargo_manifest_validator.js` | Object validation, field checks, and unit normalization |
| `Recipe_tracker.js` | Arrays of objects and helper functions |
| `WildLife_Traclker.js` | Object properties and object manipulation |
| `Some_calculating.js` | Arithmetic functions |
| `Some_shopping_list.js` | Array methods such as `push()`, `pop()`, `shift()`, and `unshift()` |
| `Quiz_game.js` | Quiz-game exercise |
| `Bubble_Sort.java` | Bubble sort algorithm |
| `Maximum, minimum and average value.java` | Basic statistics with arrays |

The list is illustrative; new exercises may be added over time.

## Running the examples

### JavaScript

Install [Node.js](https://nodejs.org/) and run an individual file from the repository directory:

```bash
node Card_Counting_Assistant.js
```

Replace the filename with the exercise you want to run.

### Java

Install a JDK, then compile and run a Java source file. For a file containing a `Main` class, for example:

```bash
javac "Maximum, minimum and average value.java"
java Main
```

Some files may be short snippets or exercises intended to be completed as part of a lesson. They may need small adjustments before they can be compiled or run independently.

## How to use this repository

1. Choose an exercise based on its filename.
2. Read the code and identify the programming concepts being practiced.
3. Run the example where applicable.
4. Experiment with inputs, conditions, and implementation details.
5. Refactor or extend the solution as your understanding grows.

## Project status

This is a learning-oriented repository and a work in progress. It is not a single packaged application; there is currently no common build system or one command that runs every exercise.
