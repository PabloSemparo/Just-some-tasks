# Just Some Tasks

A personal collection of programming exercises, practice tasks, and small code examples.

The repository is primarily focused on **JavaScript**, with a few examples in **Java**. Each exercise is stored as a separate source file and can be explored independently.

## Topics

- **JavaScript fundamentals** — variables, data types, operators, and expressions.
- **Functions and control flow** — parameters, return values, conditions, loops, and callbacks.
- **Arrays and objects** — creating, reading, updating, and iterating over data.
- **String manipulation** — formatting, masking, truncating, and analyzing text.
- **Math and calculations** — arithmetic, random values, and basic statistics.
- **Small programs** — quiz game, lunch picker, recipe tracker, wildlife tracker, and cargo manifest validator.
- **Algorithms** — sorting and basic array-processing examples in Java.

## Running the examples

### JavaScript

Install [Node.js](https://nodejs.org/), clone the repository, and run an individual exercise:

```bash
git clone https://github.com/PabloSemparo/Just-some-tasks.git
cd Just-some-tasks
node lunch-picker.js
```

Replace the filename with the exercise you want to run. Most files are standalone examples and do not require additional packages.

### Java

Install a JDK and compile the selected source file:

```bash
javac MaximumMinimumAverageValue.java
java MaximumMinimumAverageValue
```

For the bubble sort example, inspect the file first: it may be a partial exercise rather than a standalone class with its own `main` method.

## How to use this repository

1. Choose an exercise by its filename or topic.
2. Read the code and identify the concepts being practiced.
3. Run the file where it is a complete, runnable example.
4. Experiment with inputs and implementation details.
5. Refactor or extend the solution as your understanding grows.

## Project status

This is a learning repository and an ongoing collection of exercises, not a single packaged application. There is no shared build system, test suite, or command that runs every file.
